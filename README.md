# E-Commerce Customer Behavior Analytics

## Project Overview

This project analyzes customer behavior in an e-commerce electronics store using Power BI.

The main goal is to understand the customer journey from product viewing to cart addition and purchase, and identify where customers drop off.

## Objectives

- Analyze customer shopping behavior
- Understand the customer journey
- Identify customer drop-off points
- Analyze products, categories, and brands
- Analyze purchase revenue
- Build an interactive Power BI dashboard
- Generate useful business insights and recommendations

##  Tools & Technologies

- Power BI
- Power Query
- DAX
- Kaggle Dataset

##  Dataset

The dataset contains e-commerce event history from an electronics store.

It includes information such as:

- Event Time
- Event Type
- Product ID
- Category ID
- Category Code
- Brand
- Price
- User ID
- User Session

### Event Types

- View
- Cart
- Purchase

## Dashboard Pages

### 1. Overview
Provides a summary of customer activity and overall e-commerce performance.

### 2. Product Analysis
Analyzes product views, cart additions, purchases, brands, and purchase revenue.

### 3. Customer Analysis
Analyzes customer activity, users, sessions, and customer behavior over time.

### 4. Category & Brand Analysis
Analyzes product categories, brands, and purchase revenue.

### 5. Customer Journey Analysis
Analyzes the customer funnel:

**Sessions → Product Views → Cart Additions → Purchases**

This page helps identify where customers drop off during the shopping journey.

### 6. Insights & Recommendations
Provides key findings from the analysis and business recommendations.

##  Customer Journey Funnel

The project focuses on three major stages:

**View → Cart → Purchase**

The dashboard uses DAX measures to calculate session-based funnel metrics and conversion rates.

##  Key Insights

- Customer activity is high at the product-view stage.
- A smaller number of sessions continue to cart and purchase.
- Some brands receive higher customer interest than others.
- Purchase revenue is concentrated among selected brands and categories.
- The customer journey shows opportunities to improve conversion.

##  Business Recommendations

- Improve product information and product pages.
- Provide attractive offers and promotions.
- Reduce cart abandonment.
- Simplify the checkout process.
- Focus promotions on high-performing brands and categories.
- Improve the performance of products with high views but fewer purchases.

##  Dashboard

The final dashboard was created using Power BI with interactive visuals, KPIs, filters, and customer journey analysis.
